# Top Win · Christmas Journey landing page

Daily advent-style landing page for the Top Win brand (26 days, 1–26 December 2026; markets DE, NL, EN_GBP, RO_MDL), built with Vite and vanilla JS and deployed to GitHub Pages on every push to `main`. Live URL: https://mkt-sls.github.io/tw-xmas-journey-lp/ . Texts and links are pending (step 2), design is pending (step 3). Run `npm ci`, then `npm run dev`, `npm test` or `npm run build`.
